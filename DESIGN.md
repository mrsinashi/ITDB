# ITDB — концепция оформления

Этот документ — главный ориентир для любых изменений интерфейса. Прежде чем
добавлять страницу, блок, кнопку или цвет, сверяйся с ним. Если решение
противоречит документу, сначала обсуди его с автором, потом правь документ,
и только потом код.

## 1. Суть

ITDB — рабочий инструмент учёта: на экране много однотипных данных, их
просматривают быстро и подолгу. Отсюда всё остальное:

- **Плотность и читаемость важнее «воздуха».** Строки низкие, шрифт мелкий,
  но всё выровнено и разделено, глазу есть за что зацепиться.
- **Эталон — страница «Таблица».** Любой новый экран должен выглядеть так,
  будто он часть этой таблицы: те же шапки, линии, отступы, шрифт.
- **Строго и спокойно, без «хайпа».** Никаких крупных скруглений, пастельных
  подложек, теней-облаков, «карточек» с большими полями, пилюль, градиентов,
  декоративных анимаций. Это воспринимается как дешёвое и неудобное.
- **Цвет — только со смыслом.** Интерфейс нейтрально-серый; цвет схемы
  появляется в строго определённых местах (раздел 4), красный — ошибки и
  дубли, зелёный — «сохранено», бежевый — строка под курсором.
- **Текст чёрный.** Второстепенный серый — только для служебного (подсказки,
  «пусто», счётчики на панели). Данные в таблицах всегда чёрные: пользователь,
  объект, время, подписи полей. Главное в строке — жирным: имя объекта в
  Истории, изменённое поле в истории карточки, HOSTNAME в таблице.

## 2. Сетка, размеры, шрифт

| Что | Значение |
|---|---|
| Шрифт | системный (`Inter, Segoe UI, …`), 13px базовый |
| Главная таблица | 12px, ячейка `3px 6px`, строка ~20px |
| Дерево, История, Справочники, карточка | 12–13px, строки 24–25px |
| Шапка таблиц | 24px, 12px, полужирный 600 |
| Панель под меню | высота ~35px, кнопки 12px, `padding 3px 10px` |
| Отступ страницы | 10px сверху, 12px по бокам — одинаково на всех страницах |
| Скругление | **одно на всё**: `--radius: 3px` (кнопки, поля, блоки, меню, диалоги). Внутренние элементы у края блока — 2px |
| Жирный | 600 — шапки, строки-группы, имя в карточке. 700 — только HOSTNAME и выбранное оформление значений |

Правила:

- Высоту не тратить впустую. Строка «потолще» допустима только у строк-групп.
- Разделители видимые: сетка `#e5e5e5`, линии шапок/групп `#d8d8d8`/`#cfcfcf`.
  Незаметных «еле серых» границ не бывает.
- Ничего не приклеивать к верхней границе области: отступ — снаружи
  прокрутки, липкая шапка стоит на месте, рамка и скругления видны всегда.
- Ширина блоков — по содержимому (как дерево: по самому широкому узлу, даже
  свёрнутому), а не «на пол-экрана».

## 3. Серые плоскости (иерархия)

Одна шкала для всех страниц — переменные в начале `app.css`:

| Переменная | Цвет | Где |
|---|---|---|
| `--grid-head-bg` / `--gray-head` | `#f0f0f0` | шапки таблиц, панель под меню |
| `--gray-group` | `#e9e9e9` | строки-группы: адрес в дереве, день в истории, группа в карточке — **везде одинаково** |
| `--surface-alt` | `#f5f5f5` | подписи полей в карточке, строка «Весь столбец» |
| `--gray-line` | `#d8d8d8` | рамки блоков, линии под шапками |
| `--group-line` | `#c8c8c8` | линии над и под строкой-группой (адрес в дереве) |
| `--grid-line` | `#e5e5e5` | сетка внутри таблиц |

Правило иерархии: **шапка никогда не светлее групп.** Если шапка серая, группы
не темнее её; если шапка цветная (цвет схемы) — группы серые.

Серый — ровно серый. Никаких «слегка розовых/зеленоватых» оттенков серых
плоскостей под цвет схемы.

## 4. Цвет схемы и акценты

### Схемы
Пять тёмных спокойных схем, выбор — шестерёнка в меню (личная настройка,
`users.prefs.theme`): красная (по умолчанию), зелёная, синяя, тёмно-серая,
бирюзовая. Задаются в `html[data-theme="…"]` набором переменных:

- `--nav-bg` — самый тёмный тон: верхнее меню, шапка карточки ПК;
- `--brand` — тон акцента, чуть светлее меню: акцентные шапки таблиц,
  включённые кнопки, аватар (значения подобраны автором вручную);
- `--brand-dark` — линии на фоне `--brand`;
- `--brand-accent` — акцентные границы блоков, линия режима правки, значки
  (сейчас совпадает с `--brand`);
- `--brand-focus` — рамка поля в фокусе.

Значения `--brand` / `--brand-accent` в схемах выставлены автором — не
менять без согласования.

Новый цвет в правилах CSS не пишется напрямую — только через переменные.
Новая схема = новый блок `html[data-theme]` + строка в `THEMES` (app.js) +
значение в `THEMES` на сервере (`api_auth.py`).

### Где цвет схемы есть
- верхнее меню и полоска загрузки;
- шапка карточки ПК — самая тёмная плоскость карточки;
- включённые кнопки панели (`✎ Правка`), линия режима правки;
- **акцентные шапки** таблиц Дерева, Истории и блоков Справочников —
  включаются/выключаются для каждой страницы шестерёнкой справа на её панели
  (`prefs.accent_headers.{tree,history,choices}`, по умолчанию включено);
- **акцентные границы блоков** (общая галочка в настройках,
  `prefs.accent_borders`): рамки блоков цветом `--brand-accent`, толщина та же,
  скругления сохраняются (как рамки окон Windows 11).

### Где цвета схемы нет
- главная таблица целиком (шапка серая, акцентов нет);
- карточка ПК ниже шапки (группы и разделы — только серые линии);
- кнопки и сетка внутри таблиц;
- серые плоскости (раздел 3);
- значок адреса в дереве — всегда тёмно-красный `#9b1c1c`.

## 5. Состояния

| Состояние | Как выглядит |
|---|---|
| Строка под курсором | бежевый `--row-hover-bg` `#f9e6ce` во всех таблицах и списках; вертикальные разделители внутри строки — `--row-hover-line`, блочки с числами — `--row-hover-chip` (боковые и горизонтальные линии не меняются) |
| Сохранено | зелёная вспышка 1.4 с слоем поверх фона (inset-тень + `@property --flash`), гаснет в реальный фон ячейки |
| Сохраняется | новое значение уже в ячейке, приглушено (opacity .55) |
| Дубль | красный фон `--dup-bg` |
| Правка | редактор поверх ячейки, рамка `--brand`; Enter / Shift+Enter / Esc |
| Нет значения/пусто | `—` или серый текст «пока нет» |
| Копирование | значение без подсветки, при наведении справа значок `--copy-ico` `#b98a4e` (в тон бежевой строки) |
| HOSTNAME | подчёркивание при наведении только в режиме просмотра |

## 6. Компоненты

- **Панель под меню** (одинакова на всех страницах): слева счётчик/подпись,
  по центру поиск (× и Esc), справа кнопки; постоянные кнопки не прыгают,
  появляющиеся встают слева от них. Крайняя правая кнопка на Дереве, Истории,
  Справочниках — шестерёнка «Настройки страницы».
- **Кнопки** `.btn` — 12px, рамка, радиус 3px. Иконка + текст, без эмодзи.
- **Выпадающие меню** — «угол в угол» с кнопкой (`.dropdown.attached`), радиус
  3px, наведение — серый `--menu-hover-bg`.
- **Меню из верхней панели** (пользователь, настройки) — без рамки, край фоном
  и тенью, ширина кратна 4px (иначе на 125/150% край «съезжает» на пиксель).
- **Рамка блока** (таблица Дерева, История, блоки Справочников,
  пользовательские поля) — единая техника: блок `overflow: hidden` +
  скругление, а сама линия рисуется псевдоэлементом `::after` ПОВЕРХ
  содержимого, цвет — переменная `--frame`. Линия — «кольцо» из градиента
  под маской: на высоте шапки (`--head-h`) она цвета шапки (`--frame-head`:
  цвет схемы при акцентной шапке), ниже — `--frame`; поэтому серая рамка не
  обводит цветную шапку. Так фон шапки уходит под линию
  (нет светлого просвета у дуги), рамку не перекрывают строки и углы полосы
  прокрутки. Ничего не должно выходить за рамку: выносные элементы (плашка
  действий дерева) ставятся снаружи блока, в обёртке.
- **Таблица-блок** (Дерево, История): серая (или акцентная) шапка 24px, сетка
  на всех ячейках, строки-группы `--gray-group` с линиями сверху и снизу
  темнее обычных (`--group-line`) и без вертикальных разделителей. Прокрутка —
  внутри рамки (обёртка с рамкой > область прокрутки); шапка липкая, в Дереве
  под ней закрепляется текущий адрес, в Истории — текущий день.
- **Плашка действий строки** (дерево) — одна на блок, справа снаружи рамки у
  строки под курсором; строка при этом остаётся подсвеченной.
- **Блоки Справочников** — вертикальные, в порядке столбцов таблицы, сеткой
  слева направо; шапка + строка «Весь столбец» + значения + строка добавления.
- **Число-метка** («блочок»): радиус 3px, серый фон (`#d6d6d6`–`#e6e6e6`, темнее подложки под ним),
  тёмный текст 11–12px. У строк-групп дерева — просто число, крупнее.
- **Карточка ПК** — панель слева 440px: шапка цвета схемы, таблица «подпись |
  значение», группы серые, разделы ниже с заголовком; История — с числом
  изменений блочком и стрелкой справа, свёрнута при открытии.
- **Диалоги и сообщения** — `confirmDialog()` / `toast()`; никаких `alert`.

## 7. Тексты

- Интерфейс по-русски, без канцелярита и без «разговорности».
- Даты и время — только цифрами: `26.09.2026`, `10:52:52`. Без «сегодня»,
  «сент.» и т. п.
- Названия столбцов: в самой таблице и выгрузке — короткие (`Каб`, `OS`),
  везде вне таблицы — полные (`columnTitle()` / `fullName` в `COLUMN_DEFS`):
  «№ Кабинета», «Операционная система (ОС / OS)» и т. д.
- Подсказки (`title`) — там, где смысл не очевиден (поле «Код», кнопки-значки).

## 8. Чего не делать (из замечаний автора)

- крупные скругления, «обтекаемые» формы, пилюли, большие тени;
- светлые пастельные подложки цвета схемы на заголовках и группах;
- еле заметные границы или их отсутствие в таблицах;
- «толстые» строки и лишние отступы;
- разные выделения для частей одного значения (часы жирно, секунды бледно);
- цветной текст для обычных данных (объекты, пользователи);
- рамки и линии, которые режут соседние элементы (светлая полоса поверх меню,
  вертикальная линия через акцент);
- всплывающие окна вместо прямых элементов управления там, где их можно
  поставить в строку;
- решения «на глаз» без проверки на масштабах 100%, 125%, 150%.

## 9. Техника

- Все цвета, размеры скруглений — переменные в `:root` (`app.css`).
- Спорные варианты оформления — переключатели `UI_OPTIONS` в начале
  `app.js`; `false` возвращает прежний вид.
- Личные настройки — `users.prefs` (JSONB) через `PATCH /api/auth/me/prefs`:
  `theme`, `accent_borders`, `accent_headers`. Кэш схемы — `localStorage`
  `itdb.theme`, применяется до отрисовки страницы.
- Оформление данных — Справочники: стиль столбца (`column_styles`) и стиль
  значения (`choices`), значение перекрывает столбец; у IP оформляются
  подсети /24 (`ipSubnetKey`).
- Перед сдачей: скриншоты всех затронутых страниц (Playwright), проверка
  ролей admin / reader, масштаб 125%.
